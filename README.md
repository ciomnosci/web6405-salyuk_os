
## Лабораторная работа №3

**Цель:** изучение основ JavaScript.

**Что сделано:** в файле `lab3/src/core.js` реализованы функции:

- `isInteger(n)` — проверка числа на целостность через побитовые операторы;
- `even()` — массив чётных чисел от 2 до 20;
- `sumTo(n)` — сумма чисел до `n` через цикл;
- `recSumTo(n)` — сумма чисел до `n` через рекурсию;
- `factorial(n)` — факториал числа;
- `isBinary(n)` — проверка, является ли число степенью двойки;
- `fibonacci(n)` — N-е число Фибоначчи;
- `getOperationFn(initialValue, operatorFn)` — функция-аккумулятор на замыкании;
- `sequence(start, step)` — генератор арифметической последовательности;
- `deepEqual(a, b)` — глубокое сравнение объектов.
