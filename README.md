# Лабораторная работа № 2

**Тема:** Многостраничный сайт «Топ-3 проступка мистера Чепы»

**Цель:** изучение основ HTML и CSS.

**Технологии:** HTML5, CSS3. Без JavaScript, без Bootstrap и любых
сторонних библиотек и фреймворков — всё реализовано вручную.

## Страницы сайта

1. **Главная (`index.html`)** — кто такой мистер Чепа, его портрет
   и сводная таблица «Рейтинг проступков».
2. **3 место (`crime3.html`)** — как Чепа превратил шторы в скалодром.
3. **2 место (`crime2.html`)** — почему нельзя оставлять ничего съедобного
   (и несъедобного) на виду.
4. **1 место (`crime1.html`)** — легендарное падение в унитаз.

## Что реализовано по требованиям

### HTML
- Блочные элементы: `<header>`, `<nav>`, `<main>`, `<section>`, `<footer>`,
  `<table>`, `<ul>`.
- Строчные элементы: `<a>`, `<span>`, `<strong>`, `<em>`.
- Ссылки: навигационное меню из 4 страниц, работает на каждой странице.
- Изображения: по одному и более на каждой странице.
- Таблица: «Рейтинг проступков» на главной странице.
